# JavaScript Assignments and Capstone Project

This repository contains six standalone JavaScript assignments and the Interactive Product Inventory & Analytics Dashboard capstone project.

## Live project

Open the deployed dashboard: [https://live-project.vercel.app](https://live-project.vercel.app)

## Repository layout

- `assignments/assignment-1.js` — variables, data types, and console output
- `assignments/assignment-2.js` — operators, numeric input, and tip calculation
- `assignments/assignment-3.js` — conditional logic, switch, and grade status
- `assignments/assignment-4.js` — for, while, do...while, break, and continue
- `assignments/assignment-5.js` — functions, default parameters, and scope
- `assignments/assignment-6.js` — product objects and array methods
- `project/index.html` — interactive browser dashboard
- `project/inventory-dashboard-console.js` — console edition of the capstone

## Run the assignments

Install Node.js 18 or later, then open a terminal in the `assignments` folder and run any assignment, for example:

```sh
node assignment-1.js
```

Assignment 2 asks for a subtotal and tip. Enter `100` and `15` to match the brief's sample output.

## Open the dashboard locally

Open `project/index.html` in a browser. The dashboard lets you add and remove products, search and filter the inventory, and see category badges and financial summaries update. Product categories use the thresholds defined in the page's JavaScript: Budget up to $100, Standard up to $500, and Premium above $500.
